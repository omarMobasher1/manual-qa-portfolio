# ShopEasy Manual QA Portfolio

This repository is an entry-level manual software testing portfolio built around a small e-commerce demonstration application. It shows how requirements are analyzed, tests are designed and executed, defects are reported, and results are summarized.

## Live application

**[Open the ShopEasy application](https://omarmobasher1.github.io/manual-qa-portfolio/app/)**

Demo credentials: `tester@example.com` / `Password1!`

## Project scope

The tested features are:

- User login
- Product search and category filtering
- Shopping-cart quantity and totals
- Promotional codes
- Checkout validation

The application is intentionally small and contains known defects so the defect reports are reproducible. This is a personal portfolio project, not commercial work.

## Test approach

The portfolio demonstrates:

- Equivalence partitioning and boundary value analysis
- Decision-table-based promotional-code testing
- Positive and negative testing
- Exploratory testing
- Requirements traceability
- Risk-based prioritization
- Clear defect reporting

## Repository contents

| File | Purpose |

## How to reproduce the testing

1. Download or clone the repository.
2. Open `app/index.html` in Chrome, Edge, or Firefox.
3. Use the credentials `tester@example.com` / `Password1!`.
4. Follow the steps in `docs/test-cases.csv`.
5. Compare observed behavior with the linked defect reports.
